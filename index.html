CHECK THE IMPLEMENTATION

Where the release differs

  • Two semantic calls. Analyze defines expectations; Verify answers eight questions in one call. Eight independent verifier agents are not executed.
  • Physics has a coverage limit. The bundled wind/flag example has no registered physical-law engine and returns not applicable.
  • Physical observation differs. Appendix C combines visual and causal scores; this release returns only the PAVRM video score. Reproducing the code is not identical to reproducing that formula.
  • Judge substitution. Our fresh semantic runs use local Qwen3-VL-8B rather than the authors’ GPT-5.5.
  • Six is not 330. Fresh rollout evaluation covers the six bundled videos. The 100-case public set supplies initial worlds and plans, not all model rollouts.
